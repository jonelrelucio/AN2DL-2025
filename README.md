# AN2DL-challenges-2025-26

## Challenge 1: Time Series Classification

In this challenge, a collection of multivariate time
series was given. Each sequence corresponds to
a single subject and consists of 160 measurements
taken at different time instants from several input
channels. The objective is to perform time series
classification to predict the true pain status of
the subjects, classifying them into one of three
categories: no pain, low pain, and high pain using
models based on Recurrent Neural Networks architectures, optimizing for the resulting F1-score.
